# 🎮 Old Classics
## 📚 Estudo dos Clássicos

Criei esse projeto com o objetivo de entender como os jogos antigos eram desenvolvidos e quais conceitos fundamentais eles utilizavam.

O projeto recria quatro jogos clássicos:

🏓 Pong <br>
🧱 Arkanoid <br>
🐍 Snake <br>
🧩 Tetris

Durante o desenvolvimento aprendi bastante sobre:

Manipulação de grid
Sistema de colisões
Física básica
Estruturação de projetos
Conceitos iniciais de Game Design
